
Кейсы ELMA и Synaptick

В репозитории собраны решения трёх аналитических кейсов. Первый и второй кейсы находятся в папках case1_elma и case2_elma. Решение третьего кейса находится в файле case3_synaptick.pdf в корне репозитория.

Кейс 1. Поиск аномалий

Исходные данные находятся в файле case1_elma/data.csv. Скрипт case1_elma/case1.py содержит код поиска аномалий и при запуске сохраняет результат в файл anomalies.csv.

Готовое решение для просмотра — case1_elma/case1_anomalies.xlsx. В таблице указаны идентификатор заявки, тип аномалии и пояснение к ней в столбце Explanation.

Кейс 2. Восстановление процесса закупки

Условие задания находится в файле case2_elma/task(2).md, описание данных — в dataset_description(2).md, а требования к ответу — в submission_template(2).md. Исходный журнал событий — students(1).csv.

Готовая схема процесса находится в process_discovery.png. Файл variants.csv содержит маршруты заявок и их частоты, а student_transitions.csv — переходы между действиями.

Пояснения к решению приведены в отчёте case_2.pdf. Ход анализа, расчёты и построение схемы находятся в ноутбуке case2.ipynb. Файлы variants_template.csv и student_transitions_template.csv являются пустыми шаблонами, а не результатами.

Для повторного запуска ноутбука нужно заменить записанный в нём путь к students(1).csv на путь к файлу на своём компьютере.

Кейс 3. Продуктовые гипотезы

Готовое решение и пояснения находятся в файле case3_synaptick.pdf. В отчёте представлены гипотезы, наблюдения, расчёты и выводы. Отдельных исходных данных и кода для этого кейса в репозитории нет.
